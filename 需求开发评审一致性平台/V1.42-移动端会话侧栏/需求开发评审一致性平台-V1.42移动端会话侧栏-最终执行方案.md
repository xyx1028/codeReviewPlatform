# 需求开发评审一致性平台 V1.42：移动端会话侧栏最终执行方案

## 1. 背景与目标

代码问答手机端目前把历史会话压缩成内容区顶部的折叠条。用户希望像参考图一样，从左侧菜单直接看到按标题排列的历史会话，并可快速切换。

## 2. 范围与非目标

- 仅调整 `/ask` 在不大于 900px 视口的历史会话入口、展示和收起行为。
- 复用现有平台导航抽屉和现有会话查询、置顶、重命名、删除能力。
- 桌面布局、数据库、RPC、Worker 和会话排序规则不变。

## 3. 当前实现与问题

- `src/App.tsx` 的 `Shell` 已有手机端菜单按钮、左侧 `Sider`、遮罩、Esc 关闭及页面切换自动收起。
- `src/pages/CodeQaPage.tsx` 单独维护 `mobileHistoryExpanded`，手机端历史会话显示为内容区上方 52px 折叠条，展开仅 220px。
- `src/App.css` 为该折叠条限制高度，长会话列表难以浏览，也没有与左侧菜单合并。

## 4. 需求与验收标准

1. 手机端打开平台菜单后，左侧直接显示置顶与最近会话标题，不需再次展开。
2. 列表独立滚动，当前会话有浅灰选中态；长标题截断，管理菜单仍可触达。
3. 选择历史会话或新建会话后，菜单关闭并显示对应内容。
4. 点击遮罩、关闭按钮或按 Esc 均能收起；关闭后隐藏列表不可获得键盘焦点。
5. 内容区不再预留历史折叠条高度；桌面端原侧栏保持可用。

## 5. 总体设计

- `Shell` 继续拥有手机导航开关，并将手机状态与关闭回调传给 `CodeQaPage`。
- `CodeQaPage` 保持唯一一份会话列表 DOM；手机端用 CSS 将其定位到左侧导航下半部，作为导航抽屉中的历史区。
- 使用现有 `listCodeQaConversations` 与 `partitionCodeQaConversations` 数据流，保留已有列表操作。

## 6. 数据与接口设计

不涉及数据库、类型、API、RPC、事件或配置变化。

## 7. 前端与 Worker/运行时改造

- 前端：调整 `src/App.tsx`、`src/pages/CodeQaPage.tsx`、`src/App.css`。
- Worker、DSH、权限、预算、Session 与工具：不涉及。

## 8. 安全、兼容与回滚

- 服务端会话权限不变，列表仍只取当前用户的会话。
- 不大于 900px 使用新布局；宽屏继续沿用现有侧栏。可回滚前端修改，无数据迁移或在途任务影响。

## 9. 实施步骤与文件范围

1. 移除手机端独立历史折叠状态，复用平台导航状态。
2. 更新手机端历史列表、导航宽度、滚动与选中态样式。
3. 运行类型检查、构建和手机视口烟测，记录结果。

主要文件：`src/App.tsx`、`src/pages/CodeQaPage.tsx`、`src/App.css`、本执行方案。
