# 需求开发评审一致性平台 V1.41：移动端适配最终执行方案

## 1. 背景与目标

手机浏览器中，登录后的页面仍使用桌面双栏布局，264px 导航侧栏占用可视宽度，主要内容被挤压。本次让平台随视口自动切换布局，使手机能够正常浏览和操作已有功能。

## 2. 范围与非目标

- 覆盖登录后的共享导航、代码问答、评审批次及管理页面的窄屏容器；登录页已有手机样式，保留并回归检查。
- 目标宽度包括 320、375/390、430px 手机及 768px 平板；桌面保留原有布局。
- 不改变评审业务、权限、API、数据库和 Worker 行为；宽表格允许在表格内部横向滚动。

## 3. 当前实现与问题

- `index.html` 已设置 `width=device-width` viewport，浏览器缩放配置正确。
- `src/App.tsx` 的 `Shell` 无条件渲染 264px `Sider`，账号菜单通过 Portal 固定在左下角。
- `src/App.css` 虽有部分页面媒体查询，但窄屏仍保留侧栏占位；代码问答的历史会话和“新建对话”还有桌面固定定位规则。
- `src/index.css` 的登录卡片固定声明 440px 宽度，390px 视口实测 `documentElement.scrollWidth` 为 456px。

## 4. 需求与验收标准

1. 视口不大于 900px 时，导航默认收起，主内容获得全宽；顶部提供清晰的导航入口。
2. 打开导航可访问产品、评审、日志和账号入口；点击页面、导航项或关闭按钮后可收起，键盘可关闭。
3. 代码问答历史、新建对话、输入区域在手机宽度不被固定侧栏遮挡。
4. 页面容器与常用卡片不产生整页横向滚动；需要宽列的表格在自己的区域滚动，字段仍可读取。
5. 宽视口仍显示原有侧栏和内容工作面，路由与权限保持原样。

## 5. 总体设计

- 共享 `Shell` 根据 `matchMedia('(max-width: 900px)')` 管理手机导航状态，保留同一套导航 DOM，窄屏将侧栏作为浮层展示。
- 手机顶部增加品牌和菜单按钮；遮罩及关闭按钮管理浮层；账号入口跟随侧栏，避免固定 Portal 留在已收起的导航位置。
- CSS 在窄屏取消侧栏的布局占位，修正问答历史定位，并使表格容器局部滚动。
- 已有问答会话使用固定视口高度、可滚动消息区和底部输入区；欢迎页保持页面纵向滚动。

## 6. 数据与接口设计

不涉及数据库、API、RPC、事件、配置或持久化变化。

## 7. 前端与 Worker/运行时改造

- 前端：修改 `src/App.tsx`、`src/App.css`、`src/index.css` 和 `src/pages/CodeQaPage.tsx`。
- Worker、DSH、权限规则、预算、Session 和工具：不涉及。

## 8. 安全、兼容与回滚

- 导航仅改变展示方式，服务端权限与现有菜单筛选不变。
- 断点为 900px，桌面布局不变；关闭导航时防止隐藏菜单获得键盘焦点。
- 可回滚本次前端文件及本文档；不涉及数据迁移和在途任务。

## 9. 实施步骤与文件范围

1. 调查共享壳层和主要页面的现有宽度约束。
2. 实现手机导航、账号菜单和页面容器响应式规则。
3. 修正代码问答及表格局部布局，检查手机与桌面视口。
4. 运行前端类型检查、构建及浏览器烟测，记录真实结果。

主要文件：`src/App.tsx`、`src/App.css`、`src/index.css`、`src/pages/CodeQaPage.tsx`、本执行方案。

## 10. 验证结果

- `npm run web:typecheck`：通过。
- `npm run test:web`：21 个测试文件、253 个测试通过。
- `npx oxlint src/App.tsx src/pages/CodeQaPage.tsx`：退出码 0；仅报告这两个文件原有的 4 条 React hooks 告警，本次新增代码无告警。
- 浏览器连接本地 Supabase 测试账号验证：390px 登录页从 456px 页面宽度修正为 390px；320px 和 390px 下问答、评审列表、用户故事、默认能力策略页面均无整页横向溢出。评审表格容器在 390px 下为 364px 可视宽、1070px 可滚动宽；导航打开、路由切换自动关闭、Esc 关闭均通过。320×700 已有问答会话的输入框底边为 688px，在视口内。768px 为手机/平板导航，1280px 保留桌面侧栏。
- `npm run build`：最终修改后通过。Vite 提示既有大包体积告警，不影响本次构建通过。
- 原计划使用 `agent-browser` CLI 做视觉烟测；本机该命令不可用，改用 Codex 内置浏览器设置 320、390、768、1280px 视口，检查实际截图与 DOM 宽度。临时浏览器视口已恢复。
- 用户故事页调用 Linky 时提示内网接口不可达，属当前测试网络限制，与本次页面适配无关。
